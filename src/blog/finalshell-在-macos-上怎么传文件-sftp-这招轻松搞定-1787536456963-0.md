作为一个macOS用户，我过去常常用命令行`scp`命令来传输文件到服务器，虽然效率高，但对于一些零碎的文件管理，或者需要浏览目录结构时，那简直是噩梦。尤其是我刚接触服务器运维那会儿，每次都要敲一堆路径，生怕敲错。直到我找到了 FinalShell，它彻底改变了我在macOS上管理服务器文件的方式。

去年年底，FinalShell macOS 客户端更新到了 4.6.0 版本，增加了不少，用起来更顺手了。今天就跟大家聊聊，怎么用 FinalShell 在 macOS 上轻松搞定 SFTP 文件传输。

![配图说明](/static/images/finalshell-sftp-macos.jpg)

## FinalShell macOS 版安装与服务器连接

首先，你需要确保 FinalShell macOS 客户端已经安装并成功连接到服务器。

### 1. FinalShell 的安装

访问 FinalShell 官网下载 macOS 版本，通常会得到一个 `.dmg` 镜像文件。双击打开后，你只需把 FinalShell 图标拖拽到“Applications”文件夹里，安装就完成了。是不是比想象中简单？

### 2. 连接你的服务器

打开 FinalShell，你会看到主界面左侧的“会话”树形结构。点击左上角的“文件”菜单，选择“新建会话”，或直接点击工具栏上的“新建”按钮（一个加号图标），然后选择“SSH会话”。

在弹出的“新建 SSH 会话”窗口里，你需要填入服务器的连接信息。
-   **名称：** 方便自己识别的名字，如“我的阿里云服务器”。
-   **主机：** 你的服务器 IP 地址或域名。
-   **端口：** SSH 端口，默认为 22。
-   **认证方式：** 选择“密码”或“密钥”。如果选择密码，填入用户名和密码；如果选择密钥，则需要提前配置好 SSH 密钥。想了解密钥配置细节，可以参考：[FinalShell 如何配置 SSH 密钥](/blog/finalshell-ssh-key-configuration/)。

填写完毕，点击右下角的“确定”按钮。你的服务器已成功添加到会话列表。双击会话，输入密码，即可成功连接到服务器。连接成功后，你会看到终端界面，底部也会自动加载 SFTP 面板。

## 轻松三步，搞定 SFTP 文件传输

现在，我们来聊聊 FinalShell 的核心功能之一：SFTP 文件传输。有了它，上传下载文件就像在 Finder 里拖拽一样简单。

### 第一步：打开 SFTP 视图

当你成功连接到服务器后，FinalShell 窗口底部会自动出现 SFTP 的文件管理器视图。如果关闭了，你可以在顶部的菜单栏中找到“视图” -> “SFTP 文件管理器”来重新打开它。这个视图通常分成左右两栏：左边是本地文件系统，右边是远程服务器文件系统。在本地文件系统那一栏，你可以像使用 Finder 一样浏览 macOS 上的任意目录。

### 第二步：选择本地和远程路径

在 SFTP 视图的左侧（本地文件系统），导航到你想要上传的文件所在的本地目录。同样，在右侧（远程文件系统），导航到你想要将文件上传到的服务器目录。如果你想下载文件，操作逻辑也是一样的，只是方向反过来。确保你在两边都选对了目录，避免把文件传错地方。

### 第三步：拖拽或右键操作传输文件

路径选定后，传输文件就非常简单了。
-   **上传文件：** 直接从左侧的本地文件列表，将你想要上传的文件或文件夹拖拽到右侧的服务器文件列表中的目标目录。放手后，FinalShell 会自动开始上传。
-   **下载文件：** 从右侧的服务器文件列表，将你想要下载的文件或文件夹拖拽到左侧的本地文件列表中的目标目录。
-   **右键菜单：** 除了拖拽，你也可以在文件或文件夹上点击右键，选择“上传文件”、“下载文件”、“复制”、“粘贴”、“新建文件夹”等操作。这对于一些更精细的文件管理非常方便。比如，你可以在服务器上直接新建一个目录，再将本地文件上传进去。想深入了解 SFTP 传输技巧，不妨看看这篇指南：[FinalShell SFTP 文件传输完整指南](/blog/finalshell-sftp-file-transfer/)。

整个过程可视化，进度条清晰可见，再也不用担心文件传到一半不知道状态了。对于习惯了图形界面的用户来说，这简直是福音。

## 常见问题

虽然 FinalShell 的 SFTP 功能很强大，但在实际使用中，也可能会遇到一些小问题。

### 1. SFTP 连接失败或者文件传输权限不足？

**问题描述：** 尝试连接 SFTP 时提示连接失败，或上传/下载文件时提示权限不足。
**解决办法：**
*   **检查 SSH 连接：** SFTP 基于 SSH，所以首先要确保你的 SSH 连接正常。
*   **检查用户权限：** 你连接服务器的用户是否有足够权限访问或修改目标目录？如无，尝试切换到更高权限的用户（如 root），或修改目标目录的权限和所有者。
*   **检查 SFTP 子系统：** 确保服务器 SSH 配置（`/etc/ssh/sshd_config`）中启用了 SFTP 子系统。

### 2. 文件传输速度很慢怎么办？

**问题描述：** 上传或下载大文件时，速度非常慢。
**解决办法：**
*   **网络带宽：** 检查你本地网络和服务器网络带宽。
*   **服务器负载：** 如果服务器负载高，会影响传输速度。
*   **FinalShell 设置：** 在“工具”->“选项”->“传输”中尝试调整“传输缓存大小”或“连接数”。
*   **文件压缩：** 传输大量小文件，打包成压缩文件（如 `.tar.gz`）再传输会显著提高效率。

### 3. 传输的文件出现乱码？

**问题描述：** 传输文本文件到服务器后，或从服务器下载文件后，打开文件出现中文乱码。
**解决办法：**
*   **编码设置：** 这通常是本地和服务器文件编码不一致导致。在 FinalShell 连接会话的设置中，有一个“编码”选项。尝试将其设置为与服务器文件编码一致的编码，比如 `UTF-8`。
*   **本地编辑器：** 确保你本地打开文件的编辑器也使用正确的编码格式。

希望这些小技巧能帮助你在 macOS 上更愉快地使用 FinalShell 进行 SFTP 文件传输。试试看，你会发现管理服务器文件原来可以这么简单高效！
