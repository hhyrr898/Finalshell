你是不是也遇到过这样的情况：辛辛苦苦申请了一台云服务器，却发现每次登录都要输入长长的密码，而且还担心密码被截取不安全？别担心！作为一名经常和服务器打交道的兼职作者，我深知这种痛苦。今天，我就来手把手教你如何在 Windows 上使用 FinalShell 4.5.3 这个神器，搞定 SSH 密钥登录，从此告别密码烦恼，同时还能轻松高效地传输文件！

## FinalShell 初体验：告别密码，SSH 密钥登录

密钥登录不仅更安全，也更方便，尤其适合经常需要登录服务器的我们。下面就来一步步设置。

### 1. 准备工作：SSH 密钥文件

在开始之前，你需要准备一个 SSH 私钥文件。这个文件通常是你创建服务器时生成的，或者是你通过其他工具（比如 PuTTYgen、ssh-keygen）生成的。它的格式可能是 `.pem`、`.ppk`，或者干脆没有后缀。如果你的服务器已经配置了对应的公钥，那我们直接用本地私钥就行。如果你还没安装 FinalShell，可以参考这篇教程 [/blog/finalshell-windows-install-guide/](/blog/finalshell-windows-install-guide/) 先安装好。

### 2. 新建会话并配置密钥认证

好了，我们假设 FinalShell 已经安装好，并且你手头也有了私钥文件。

1.  **第一步：启动 FinalShell，新建连接。**
    打开 FinalShell，点击软件左上角的“连接”按钮（通常是一个插头图标），在弹出的菜单中选择“SSH连接”。这会打开一个配置连接属性的新窗口。
    ![配图说明](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

2.  **第二步：填写基本信息与选择密钥文件。**
    在“SSH连接”窗口中，左侧会看到“基本”、“认证”等多个选项卡。
    *   首先在“基本”选项卡中，填写你的服务器 IP 地址（或域名）、SSH 端口（默认是 22）、以及登录用户名（比如 root 或 ubuntu）。
    *   接着，关键一步来了！切换到“认证”选项卡。在这里，你需要将“认证方式”从默认的“密码”改为“密钥”。
    *   更改后，下方会出现一个“私钥文件”的输入框。点击它右侧的文件夹图标，在文件浏览器中找到并选中你准备好的私钥文件。FinalShell 会自动识别并加载你的密钥。

3.  **第三步：保存会话并连接。**
    确认所有信息无误后，点击窗口右下角的“确定”按钮。FinalShell 会将这个会话配置保存到左侧的会话树中。双击你刚创建的会话名称，就可以尝试连接到你的服务器了！

### 3. 首次连接与信任主机

当你第一次连接一台新的服务器时，FinalShell 会弹出一个安全警告，提示你服务器的主机密钥没有被本地信任。这是正常现象，目的是防止中间人攻击。你只需要点击“接受并保存”或“是”来信任这个主机，以后连接就不会再弹出了。如果一切顺利，你会看到一个熟悉的命令行界面，恭喜你，已经成功用密钥登录到服务器了！如果想深入了解 SSH 密钥的配置细节，可以参考这篇更详细的教程：[/blog/finalshell-ssh-key-configuration/](/blog/finalshell-ssh-key-configuration/)。

## SFTP 文件传输：本地远程轻松互传

登录服务器后，我们经常需要上传下载文件。FinalShell 内置的 SFTP 功能用起来非常方便。

### 1. 进入 SFTP 界面

当你成功连接到服务器后，在会话窗口的顶部工具栏上，你会看到一个类似文件夹的图标，或者直接在右侧面板就能看到“文件”或“SFTP”标签页。点击它，就能切换到 SFTP 文件传输界面。这个界面通常会左右分栏：左侧显示本地文件系统，右侧显示服务器文件系统。

### 2. 上传文件到服务器

上传文件到服务器有两种常用方法：

1.  **第一步：拖拽上传。**
    在左侧的本地文件列表中，找到你想要上传的文件或文件夹。然后，直接用鼠标把它拖拽到右侧的服务器文件列表中你希望存放的目录。 FinalShell 会自动开始上传。

2.  **第二步：右键菜单上传。**
    在左侧的本地文件列表中，选中一个或多个文件/文件夹，然后右键点击，在弹出的菜单中选择“上传”选项。接着，在右侧的服务器视图中选择目标目录，文件就会被传过去。我个人觉得拖拽是最快捷的方式。

### 3. 从服务器下载文件

下载文件到本地和上传类似，同样非常直观：

1.  **第一步：拖拽下载。**
    在右侧的服务器文件列表中，找到你想要下载的文件或文件夹。直接用鼠标把它拖拽到左侧的本地文件列表中你希望存放的目录。

2.  **第二步：右键菜单下载。**
    在右侧的服务器文件列表中，选中一个或多个文件/文件夹，然后右键点击，在弹出的菜单中选择“下载”选项。接着，在左侧的本地视图中选择目标目录，文件就会被下载到你的电脑上。

如果你想了解更多 SFTP 的高级用法，比如权限管理、文件编辑等，可以看看这篇关于 FinalShell SFTP 文件传输的教程：[/blog/finalshell-sftp-file-transfer/](/blog/finalshell-sftp-file-transfer/)。

## 常见问题

在使用 FinalShell 和 SSH 密钥登录时，你可能会遇到一些小麻烦。别慌，这里有一些常见问题和我的经验之谈。

### 1. 密钥文件提示“无效的私钥格式”？

这通常是因为 FinalShell 对私钥格式有特定的要求。如果你的私钥是 OpenSSH 格式（比如用 `ssh-keygen` 生成的），FinalShell 有时候可能无法直接识别。

**解决办法：**
你可以使用 PuTTYgen 这个工具来转换你的私钥格式。
*   打开 PuTTYgen，点击“Load”按钮加载你现有的私钥文件（记得把文件类型改为“All Files”才能看到 `.pem` 或无后缀文件）。
*   加载成功后，点击“Conversions”菜单 -> “Export OpenSSH key (new format)” 或 “Save private key” （选择后者可以保存为 `.ppk` 格式，FinalShell 对 `.ppk` 格式支持较好）。
*   然后将转换后的私钥文件导入到 FinalShell 即可。

### 2. 连接超时或拒绝连接？

遇到这种问题，首先要冷静，然后按下面的思路排查：

**解决办法：**
*   **检查 IP 和端口：** 确认你在 FinalShell 中输入的服务器 IP 地址和 SSH 端口号（默认为 22）是否正确。
*   **服务器防火墙/安全组：** 这是最常见的原因。你的服务器防火墙（如 iptables、firewalld）或者云服务商的安全组可能没有开放 SSH 端口。确保端口 22（或你自定义的 SSH 端口）已经对外开放。
*   **本地网络问题：** 检查你的电脑网络是否正常，或者是否存在本地防火墙（如 Windows Defender 防火墙）阻止了 FinalShell 的连接。
*   **SSH 服务状态：** 登录到你的云服务商控制台，确认服务器的 SSH 服务是否正在运行。有时服务器重启后 SSH 服务未自动启动。
*   **内网 IP vs 外网 IP：** 如果是云服务器，确保你连接的是其公网 IP 地址。
*   如果排查到是防火墙或端口转发问题，可以看看这篇教程：[/blog/finalshell-port-forwarding-guide/](/blog/finalshell-port-forwarding-guide/)，或许能给你一些灵感。

### 3. SFTP 传输文件速度慢？

传输大文件时，速度慢确实让人头疼。

**解决办法：**
*   **网络带宽：** 检查你的本地网络带宽和服务器的网络带宽。带宽是决定传输速度的硬性限制。
*   **服务器负载：** 如果服务器当前负载很高，也会影响文件传输性能。
*   **地理位置：** 服务器与你的本地电脑之间 的物理距离越远，网络延迟就越高，也会影响速度。
*   **文件压缩：** 对于大量小文件，可以先在服务器端或本地打包成一个压缩文件（如 `.tar.gz`），再进行传输，这样可以减少传输过程中的协议开销，提高效率。
