作为一名长期使用 FinalShell 的老用户，昨天换了台 MacBook Pro，想着赶紧把开发环境搭起来。连接服务器自然还是首选 FinalShell，尤其是它强大的 SFTP 和端口转发功能，让我在管理服务器时省心不少。但 macOS 上的体验和 Windows 还是有些许不同，尤其是初次上手，总会遇到些小别扭。今天就来聊聊，我是怎么在 FinalShell macOS 客户端 4.5.3 版本上，搞定文件传输和端口转发的。

### FinalShell macOS 版初体验与基础连接

下载并安装 FinalShell macOS 客户端的过程我就不多说了，官网下载一路“下一步”就行。安装完成后，第一次打开，你会发现界面风格和 Windows 版保持了一致，但一些操作逻辑会更贴近 Mac 用户习惯。咱们先从最基础的服务器连接开始。

1.  **添加服务器会话**

    首先，要连接服务器，得先建立一个会话。在 FinalShell 窗口的左上角，找到“文件”菜单，点击“新建会话”，或者更快捷的方式是在左侧会话树的顶部，点击那个加号“+”。

    在弹出的“新建会话”窗口中，会看到几个必填项：主机（你的服务器 IP 地址或域名）、端口（通常是 22）、用户名（例如 root 或你的普通用户）和认证方式。密码认证最直接，输入密码就行；如果你的服务器更安全，推荐使用密钥认证。在这里，你可以选择“RSA/DSA 密钥”或者“ECDSA/Ed25519 密钥”进行配置。具体如何生成和配置 SSH 密钥，可以参考我们站内的 [/blog/finalshell-ssh-key-configuration/ FinalShell SSH 密钥配置指南]。

    填写完这些信息后，给会话起个好记的名字，比如“我的生产服务器”或者“测试环境”，然后点击“确定”保存。

2.  **快速连接与界面概览**

    会话保存成功后，它会出现在左侧的会话树里。双击你刚才新建的会话，FinalShell 就会尝试连接你的服务器。如果一切顺利，很快你就能看到熟悉的终端界面，上面显示着服务器的欢迎信息。连接成功后，屏幕中央是熟悉的终端界面，左侧的会话树会显示你保存的所有服务器连接，方便快速切换。底部则是一系列功能按钮，SFTP 和端口转发的入口就在这里。

### SFTP 文件传输：服务器与本地文件互通的桥梁

日常开发和运维，免不了要和服务器进行文件传输，比如上传本地代码到服务器，或者把服务器上的日志文件下载到本地查看。FinalShell 的 SFTP 功能用起来特别方便。

1.  **开启 SFTP 视图**

    当你的服务器会话连接成功后，在终端界面的底部工具栏，你会看到一个类似文件夹的图标，鼠标悬停时会显示“SFTP”字样。点击它，下方就会展开文件传输视图。如果你找不到这个图标，也可以尝试在“视图”菜单中寻找 SFTP 相关的选项来开启。

2.  **上传与下载文件**

    SFTP 视图分为左右两栏，左边是本地文件目录，右边是服务器文件目录。操作起来非常直观：

    *   **上传文件：** 你可以直接从 macOS 的访达（Finder）中，把文件或文件夹拖拽到 FinalShell SFTP 视图的右侧服务器目录，文件就会自动上传。你也可以在左侧本地文件栏，选中文件后，右键选择“上传”。
    *   **下载文件：** 同样地，在右侧服务器文件栏，选中你要下载的文件或文件夹，可以直接拖拽到左侧的本地目录，或者右键选择“下载”。

    无论是上传还是下载，FinalShell 都会在底部显示传输进度。我个人觉得这种拖拽方式比命令行 `scp` 效率高多了。如果你想了解更多 SFTP 的高级用法，可以看看这篇 [/blog/finalshell-sftp-file-transfer/ FinalShell SFTP 文件传输教程]。

### 端口转发：打通内外网的神器

端口转发在很多场景下都非常有用，比如你需要访问内网的数据库，或者测试服务器上某个只监听内网的服务。FinalShell 提供了方便的端口转发配置，可以把服务器的端口映射到本地。

1.  **配置本地端口转发**

    假设我需要在本地访问服务器内网的 MySQL 数据库（端口 3306）。在左侧的会话列表里，右键点击你要配置的服务器会话，选择“端口转发”。在弹出的“端口转发”窗口中，点击右下角的“新增”按钮。

    这里我们需要填写几项信息：
    *   **本地监听端口：** 比如 13306，这是你本地 Mac 上用来访问服务器内网服务的端口。
    *   **远程主机：** 填写你的服务器内网 IP 地址，如果就是本机，可以填 `127.0.0.1`。
    *   **远程端口：** 填写你要访问的服务端口，比如 MySQL 的 3306。

    配置好之后，点击“确定”保存。你可以同时配置多个端口转发规则，方便管理。

2.  **启动并测试转发**

    保存规则后，确保端口转发列表中的对应规则处于“开启”状态（前面有个绿色的勾）。这时，你就可以在本地的 Mac 上，通过访问 `localhost:13306` 来连接到服务器内网的 MySQL 数据库了。如果遇到连接问题，别忘了检查服务器的防火墙设置，确保目标端口是开放的。有关端口转发的更，请查阅 [/blog/finalshell-port-forwarding-guide/ FinalShell 端口转发实用指南]。

### 常见问题

在使用 FinalShell macOS 客户端时，你可能会遇到一些小问题，这里列举几个常见的和对应的解决办法。

1.  **FinalShell macOS 版字体显示模糊？**

    有些 Mac 用户反映，在 Retina 屏幕上 FinalShell 终端的字体看起来有些模糊。这可能是因为 Java 运行环境的渲染问题。你可以尝试在 FinalShell 的设置中（通常在“偏好设置”或“选项”里）调整终端的字体、字号，或者尝试更换终端渲染模式（如果有的话）。另外，确保你的 macOS 系统和 FinalShell 版本都是最新的，有时更新能解决这类兼容性问题。

2.  **SFTP 传输速度慢，甚至偶尔中断？**

    SFTP 传输速度受到网络环境、服务器负载等多种因素影响。如果遇到传输慢或中断，首先检查你的网络连接是否稳定。其次，尝试在 FinalShell 的 SFTP 设置中，调整传输模式，例如，有些情况下切换到 FTP 兼容模式或者调整并发传输数可能会有所改善。如果服务器距离较远，物理带宽瓶颈也无法避免。

3.  **端口转发配置后，本地还是无法访问服务？**

    端口转发不成功，最常见的原因是服务器防火墙没有放行目标端口，或者本地端口被其他程序占用。请登录服务器，检查 `firewalld` 或 `ufw` 等防火墙规则，确保你想要转发的远程端口（比如 3306）对外是开放的。同时，在 Mac 本地，可以用 `lsof -i:本地端口号` 命令检查是否有其他程序占用了你设置的本地监听端口。确保远程主机 IP 和端口配置正确无误也是非常关键的一步。
