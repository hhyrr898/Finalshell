## FinalShell 4.6.8 移动端端口转发，轻松搞定内网访问！

你是否需要用手机随时随地访问家里的 NAS 或办公室的开发服务器？传统方式可能很麻烦，但 **FinalShell 4.6.8** 移动端版本提供了一个便捷的端口转发方案。我最近在手机上尝试这个功能，发现它确实能大大简化远程管理，特别适合需要高效连接的朋友。

### 第一步：准备工作与版本确认

首先，请确保你的手机上安装的是 **FinalShell 4.6.8** 或更高版本。可以通过应用商店更新。端口转发依赖于一个稳定的 SSH 会话，所以要确保你的服务器 SSH 服务正常运行，并准备好登录凭据。如果你对 FinalShell 基础操作不熟悉，可以参考这篇 [FinalShell Windows 安装指南](/blog/finalshell-windows-install-guide/)，原理是相通的。

![配图说明](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

### 第二步：配置端口转发规则

打开 FinalShell 移动端，连接到你的目标服务器会话。连接成功后，在会话管理界面找到“会话设置”或底部/侧边栏的入口，通常会有“端口转发”或“隧道”的选项。我一般会先确认会话连接正常。

点击进入端口转发配置：

1.  **选择转发类型：** 我们以本地转发（Local Forwarding）为例。这意味着将手机上的端口流量转发到远程服务器的某个地址和端口。
2.  **设置本地监听端口：** 在手机上选一个空闲端口，比如 `8080`。
3.  **设置远程目标主机和端口：** 输入内网服务的实际地址和端口，例如 `192.168.1.100:80`（假设是你的 NAS Web 服务）。
4.  **保存并启用：** 完成配置后，保存规则并确保其处于启用状态。

如果你的服务器需要更复杂的认证方式，可以看看 [FinalShell SSH Key 配置](/blog/finalshell-ssh-key-configuration/) 的教程。

### 第三步：测试与验证

现在，端口转发已配置。要测试是否成功，在手机浏览器中输入 `http://localhost:8080` (或 `http://127.0.0.1:8080`)。如果能看到 `192.168.1.100` 上 Web 服务的页面，恭喜你，通过 FinalShell 移动端建立的隧道成功了！你可以通过这种方式访问内网服务了。

了解更多功能，比如 [FinalShell SFTP 文件传输功能](/blog/finalshell-sftp-file-transfer/) 和桌面版的 [FinalShell 端口转发指南](/blog/finalshell-port-forwarding-guide/)，都能帮你更好地利用 FinalShell。

## 常见问题

### 端口转发配置后无法访问？

检查本地监听端口是否被占用，以及远程目标主机和端口是否正确。同时，确认服务器和内网设备防火墙允许相关连接。

### FinalShell 移动端后台关闭后转发就断开了？

这是正常的。端口转发依赖活跃的 SSH 会话。应用关闭或被系统终止，SSH 会话会断开，转发也就失效了。
