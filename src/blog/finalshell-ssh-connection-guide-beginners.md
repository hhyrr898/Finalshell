刚拿到一台新的云服务器，激动之余，第一件事就是得连上去进行操作。对于不少刚接触服务器的朋友来说，怎么远程登录到服务器，就是一个小小的门槛。别担心，今天我们就用 FinalShell 这款趁手的工具，手把手教你搞定 SSH 连接，无论是用密码还是密钥，都能轻松上手。我目前用的是 FinalShell 4.6.9 版本，跟着教程走，保证你也能顺利连上。

FinalShell 作为一款集成了 SSH 客户端、FTP/SFTP 工具、网络监控等多种功能的软件，界面友好，功能强大，是很多运维和开发人员的首选。它能帮你很方便地管理远程服务器，传输文件，执行命令，简直是服务器管理的神器。

### 连接前的准备

在开始连接之前，你需要确保手头有以下信息：

1.  **服务器 IP 地址**：这就是你服务器在网络上的“门牌号”。
2.  **SSH 端口号**：默认是 `22`，但有些服务器为了安全会修改，所以请务必确认。如果你不确定，通常默认 `22` 即可。
3.  **登录用户名**：云服务器常见的有 `root`（Linux 系统管理员）或 `ubuntu`、`centos` 等发行版预设用户。
4.  **登录密码或密钥文件**：根据你的服务器设置，可能需要密码，也可能需要一个 `.pem` 或 `.ppk` 格式的私钥文件。

准备好这些，我们就可以开始连接了！

### ## 第一步：创建新的会话连接

打开 FinalShell 软件。你会看到主界面左侧有一个“会话”区域，这是你保存和管理所有服务器连接的地方。第一次使用通常是空的。

1.  **点击“连接”按钮**：在界面的左上角，通常有一个带加号的绿色连接图标，或者直接点击菜单栏的“文件” -> “新建会话”。点击后会弹出一个“新建SSH会话”的窗口。
2.  **填写基本信息**：
    *   **主机**：输入你的服务器 IP 地址或域名。
    *   **端口**：输入你的 SSH 端口号，默认为 `22`。如果你的服务器使用了非标准端口，一定要改过来。
    *   **用户名**：输入你的登录用户名，比如 `root`、`ubuntu` 等。
    *   **名称**：给这个连接起一个好记的名字，比如“我的腾讯云服务器”、“阿里云测试机”等。这个名字只在 FinalShell 里显示，方便你区分不同的服务器。

填写完毕后，暂时不要急着点“确定”，我们还需要设置登录方式。

### ## 第二步：选择登录方式

在“新建SSH会话”窗口的右侧，你会看到“身份验证”区域。这里有“密码”和“公钥”两种常用的登录方式。

#### 2.1 密码登录

如果你的服务器是通过密码进行 SSH 登录的，请选择这种方式：

1.  **选择“身份验证方式”为“密码”**：这是最简单直接的方式。
2.  **输入密码**：在“密码”字段中填入你的服务器登录密码。
3.  **勾选“保存密码”**：为了方便下次连接，你可以勾选这个选项。但请注意，在公共电脑或不安全的网络环境下，最好不要保存密码。如果你想把这些连接配置备份到其他电脑，可以参考这篇文章：[FinalShell 会话配置导出与导入](https://www.example.com/blog/finalshell-backup-session-config/)，里面有详细的备份方法。
4.  **点击“确定”**：现在，你可以点击窗口右下角的“确定”按钮了。如果一切顺利，FinalShell 就会尝试连接你的服务器，并弹出一个终端窗口，显示服务器的命令行界面。恭喜你，已经成功连接！

#### 2.2 密钥登录

如果你的服务器（特别是云服务器）提供的是密钥文件，那么你需要用这种更安全的方式登录。密钥登录通常比密码登录更安全，因为它避免了密码被暴力破解的风险。

1.  **选择“身份验证方式”为“公钥”**：将认证方式从“密码”切换到“公钥”。
2.  **选择私钥文件**：点击“私钥文件”旁边的文件夹图标，在弹出的文件选择器中找到并选中你的私钥文件。这个文件通常是 `.pem` 或 `.ppk` 格式。如果是 `.pem` 文件，FinalShell 会自动尝试转换。
3.  **输入私钥密码（如果需要）**：如果你的私钥文件在生成时设置了密码（passphrase），则需要在“私钥密码”字段中输入。如果没有，留空即可。
4.  **点击“确定”**：点击“确定”后，FinalShell 会使用你提供的私钥尝试连接服务器。成功后，你将看到熟悉的命令行界面。

### ## 第三步：连接成功后的操作

连接成功后，你会看到 FinalShell 的主界面发生了一些变化：

*   **左侧会话树**：你刚刚创建的连接会出现在左侧的会话列表中，下次想连接时，双击即可。
*   **终端界面**：主区域会显示一个黑色的终端窗口，你可以在这里输入各种 Linux 命令来管理你的服务器。比如，你可以尝试输入 `ls` 查看当前目录文件，或者 `ping baidu.com` 测试网络连通性。如果你发现终端中的中文显示有问题，出现乱码，可以看看这篇关于 [FinalShell 编码设置](https://www.example.com/blog/finalshell-encoding-charset-fix/) 的文章，里面有详细的解决办法。
*   **文件传输**：在终端界面的下方或右侧，通常会有文件管理面板，让你像使用 FTP 软件一样，方便地在本地电脑和服务器之间拖拽文件。

至此，你已经完全掌握了 FinalShell 连接服务器的两种主要方法。现在，你可以开始你的服务器探索之旅了。

### ## 常见问题

在使用 FinalShell 连接服务器时，可能会遇到一些小麻烦。我第一次用 FinalShell 的时候，也踩过一个坑，就是端口号输错了导致一直连不上，后来才发现是服务器安全组没开 `22` 端口。这里列举几个常见问题和解决办法：

1.  **问题：连不上服务器，提示 `Connection timed out` 或连接超时。**
    *   **解决办法**：这通常是网络不通畅导致的。首先，检查你输入的 IP 地址和端口号是否正确。其次，确保你的服务器防火墙（包括云服务商的安全组或本地 `iptables`）开放了 SSH 端口（默认为 `22`）。最后，检查本地网络连接是否正常，你可以尝试 `ping` 服务器 IP 地址看能否通。

2.  **问题：输入密码总是提示 `Permission denied` 或权限拒绝。**
    *   **解决办法**：这说明你的身份验证失败了。请仔细核对你输入的用户名和密码是否完全正确（注意大小写，键盘布局等）。有些服务器可能会限制 `root` 用户直接通过密码登录，或者禁用了密码登录只允许密钥登录，你需要联系你的服务器提供商或管理员确认。如果你经常需要查看之前输入的命令，可以参考 [FinalShell 命令历史](https://www.example.com/blog/finalshell-command-history-tips/) 的相关技巧。

3.  **问题：密钥登录报错 `Authenticate with public key failed` 或认证失败。**
    *   **解决办法**：密钥登录失败的原因可能比较多。首先，确认你选择的私钥文件是否正确，并且是与服务器上公钥匹配的私钥。其次，检查私钥文件本身的权限设置，在 Linux 系统中，私钥文件的权限通常需要设置为 `600`。最后，确保你的私钥文件格式正确，FinalShell 通常可以处理 `.pem` 和 `.ppk` 格式。如果私钥有密码，确保密码输入正确。
