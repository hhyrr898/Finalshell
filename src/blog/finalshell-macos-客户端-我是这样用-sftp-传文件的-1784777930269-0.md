作为一名经常和服务器打交道的开发者，我平时使用 macOS 系统，少不了和远程服务器之间传输各种文件。以前我用命令行工具 `scp`，操作起来总觉得有些繁琐。直到我开始用 FinalShell，特别是它的 macOS 客户端，SFTP 功能简直是我的救星，让我告别了敲命令的烦恼，传文件变得像拖拽本地文件一样简单。

## FinalShell macOS 客户端安装（版本 4.7.15）
如果你还没在 Mac 上安装 FinalShell 客户端，可以去官网下载最新版。我目前使用的是 FinalShell 4.7.15 版本，功能非常稳定。安装过程很简单，下载 `.dmg` 文件后拖到应用程序文件夹就行。如果你是 Windows 用户，安装步骤也大同小异，可以参考[FinalShell Windows 安装指南](/blog/finalshell-windows-install-guide/)。

## 搞定 SFTP 文件传输，告别 SCP 的繁琐！

### 第一步：连接到你的服务器

打开 FinalShell 之后，在左侧的“会话”树状列表里找到你要连接的服务器。如果没有，就点击左上角的“加号”图标新建一个会话。在弹出的连接配置窗口中，填入你的服务器 IP、端口、用户名和密码。一切就绪后，点击右下角的“连接”按钮，成功连接后你就能看到熟悉的命令行界面了。我昨天就遇到一个连接问题，发现是服务器防火墙没开端口，排查了一番才搞定。

### 第二步：打开 SFTP 窗口

当你成功连接到服务器后，你会发现界面的顶部有一个工具栏。在其中找到一个文件夹图标，旁边通常会标注“SFTP”或“文件”，点击它。一个新的文件传输窗口就会弹出来，左边是你的本地文件系统，右边就是你当前连接的服务器文件系统。这种左右分栏的设计，对经常传文件的我来说简直太友好了，一目了然。

### 第三步：上传下载文件操作

现在，你已经进入了 SFTP 传输界面，操作起来非常直观：

1.  **上传文件：** 选中本地（左侧）你想要上传的文件或文件夹，直接拖拽到服务器（右侧）的目标路径。松开鼠标，文件就会开始上传。你也可以右键点击文件，选择“上传”选项。
2.  **下载文件：** 选中服务器（右侧）你想要下载的文件或文件夹，拖拽到本地（左侧）的目标路径。同样，也可以右键点击文件，选择“下载”。
3.  **新建/删除/重命名：** 在任意一侧，你都可以右键点击空白处或文件，进行新建文件夹、删除文件、重命名等操作，就像在本地文件管理器里一样方便。

### 第四步：SFTP 传输的一些小技巧

*   **权限管理：** 在 SFTP 窗口里，你可以直接右键点击服务器上的文件或文件夹，选择“属性”或“权限”来修改文件的读写执行权限，这比在命令行里敲 `chmod` 命令要可视化得多。
*   **同步文件夹：** FinalShell 支持文件夹同步功能，如果你需要保持本地和服务器某个文件夹内容一致，可以尝试使用这个功能，它会智能地比对并传输差异文件。
*   **书签和历史：** 经常访问的路径可以添加书签，方便下次快速跳转。另外，它也有历史记录，可以让你快速回到之前访问过的目录。
*   **SSH Key 认证：** 除了密码，FinalShell 也支持 SSH Key 认证方式，这更安全也更便捷。如果你还没设置，可以参考[FinalShell SSH Key 配置教程](/blog/finalshell-ssh-key-configuration/)来加强你的服务器连接安全。

## 常见问题

### 1. 为什么 SFTP 连接成功，但无法看到文件列表或文件传输失败？

**问题描述：** 成功连接了 SSH 会话，但切换到 SFTP 界面后，右侧服务器文件列表显示为空白，或者拖拽文件提示传输失败。

**解决办法：**
这通常是由于 SFTP 服务端配置问题或防火墙阻挡。
*   **检查 SSHd 配置：** 确保服务器上的 SSH 服务（通常是 OpenSSH）支持 SFTP。在 `/etc/ssh/sshd_config` 文件中，查找 `Subsystem sftp /usr/lib/openssh/sftp-server` 或 `Subsystem sftp internal-sftp` 这一行是否被注释掉。如果被注释，取消注释并重启 SSH 服务。
*   **防火墙：** 检查服务器防火墙是否阻止了 SFTP 相关的端口（默认和 SSH 一样是 22 端口，但某些情况下会使用其他端口）。确保 22 端口是开放的。
*   **SELinux/AppArmor：** 在一些 Linux 系统上，SELinux 或 AppArmor 可能限制了 SFTP 进程访问文件。可以暂时禁用它们测试，或者配置相应的规则。

### 2. FinalShell SFTP 传输速度很慢，有什么办法可以？

**问题描述：** 使用 FinalShell 的 SFTP 功能传输大文件时，速度非常慢，等待时间过长。

**解决办法：**
*   **网络带宽：** 首先检查你本地网络和服务器网络带宽是否充足，这是最根本的因素。
*   **服务器负载：** 检查服务器当前的 CPU、内存和磁盘 I/O 负载，如果过高会严重影响传输速度。
*   **TCP 窗口：** 可以在 FinalShell 的会话设置里尝试调整“高级”选项中的 TCP 参数，比如增大 TCP 窗口大小，有时候能改善长距离传输的性能。
*   **压缩传输：** FinalShell 通常支持 Zlib 压缩传输，可以在会话设置中开启，对于文本文件等可压缩数据能有效提高速度，但对于已经压缩过的文件（如 zip、图片、视频）效果不明显，反而可能增加 CPU 负担。
