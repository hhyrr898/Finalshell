刚装好 FinalShell 4.5.12 激动不已，准备大展身手管理服务器，却发现第一步连接服务器就卡住了？别担心，作为一名日常和服务器打交道的兼职作者，我自己也经历过这样的阶段。今天这篇快讯就带你搞定 FinalShell 4.5.12 的初次 SSH 连接，保证看完就能轻松上手！如果你还没安装，可以先看这篇 [FinalShell Windows 安装指南](/blog/finalshell-windows-install-guide/)。

## 首次连接 SSH 服务器实操

### 第一步：打开 FinalShell 并新建会话
安装好 FinalShell 4.5.12 后，双击桌面图标启动软件。第一次打开时界面可能比较简洁。我们要做的就是新建一个连接。
点击软件左上角的 `文件` 菜单，然后选择 `新建 SSH 会话`。或者，你也可以直接点击工具栏上的 `新建` 图标，选择 `SSH 会话`。一个新窗口会弹出来，这是我们配置服务器信息的地方。

### 第二步：填写服务器连接信息
在弹出的 `新建 SSH 会话` 窗口里，我们需要填入几个关键信息：
*   **名称**: 给你的会话起个好记的名字，比如 '我的阿里云服务器' 或 '测试VPS'。
*   **主机**: 填入你的服务器 IP 地址或者域名。
*   **端口**: SSH 默认端口是 22，如果你的服务器修改过，请填写真实端口。
*   **认证方式**: 一般选择 `密码`。
*   **用户名**: 你的服务器登录用户名，通常是 `root` 或者你创建的其他用户。
*   **密码**: 你的服务器登录密码。
这些信息都填好后，可以点击右下角的 `测试` 按钮，看看连接有没有问题。如果显示 '连接成功'，那就太棒了！

### 第三步：保存并连接服务器
确认信息无误并通过测试后，点击 `确定` 保存这个会话。现在，你的新会话就会出现在 FinalShell 左侧的会话列表里了。
双击这个会话名称，FinalShell 就会尝试连接你的服务器。第一次连接可能会提示你保存服务器指纹（SSH Fingerprint），选择 `接受并保存` 即可。稍等片刻，如果一切顺利，你就会看到服务器的命令行界面，就可以开始输入命令管理服务器了！我自己习惯在连接成功后，先输入 `ls -l` 看看目录结构，确认连接正常。如果还需要进行文件传输，可以参考这篇 [FinalShell SFTP 文件传输指南](/blog/finalshell-sftp-file-transfer/)。

## 常见问题

### 连接失败提示“Connection refused”？
这通常意味着你的服务器防火墙阻止了 SSH 连接，或者 SSH 服务没有启动/配置错误。你需要检查服务器的安全组规则是否放行了 22 端口（或者你自定义的端口），以及 SSH 服务是否正在运行。如果你是云服务器，记得去控制台检查一下安全组设置。

### 密码输入正确但无法登录？
可能是用户名输错了，或者密码中包含特殊字符导致复制粘贴时出错。建议手动输入密码确认。另外，如果服务器开启了密钥登录，而你还在尝试密码登录，也会失败。可以参考 [FinalShell SSH 密钥配置教程](/blog/finalshell-ssh-key-configuration/) 来配置密钥登录。
