## 轻松实现端口转发

端口转发是FinalShell一个极其实用的功能，它允许您通过SSH隧道访问通常无法直接访问的内部服务。

### 本地端口转发

本地端口转发（Local Port Forwarding）是最常见的场景。它将您本地机器的一个端口映射到远程服务器上的某个端口，再由远程服务器转发到目标地址。

例如，您希望通过本地浏览器访问位于远程服务器内网的某个Web服务（如：192.168.1.100:8080）。
在FinalShell中，您可以通过以下步骤设置：
1.  在已连接的会话中，找到“隧道”或“端口转发”选项。
2.  新建一个本地端口转发规则。
3.  配置本地监听端口（例如：8000）。
4.  配置目标地址和端口（例如：192.168.1.100 和 8080）。
5.  启动转发。
此时，您只需在本地浏览器访问 `http://localhost:8000` 即可安全地访问远程内网的Web服务。

## 安全高效的SFTP文件传输

FinalShell集成的SFTP文件传输功能极大地简化了远程文件管理。无需额外客户端，您就可以在同一个界面下完成终端操作和文件传输。

### 直观的文件管理界面

连接到服务器后，FinalShell会在终端旁边提供一个文件管理面板，采用类似文件资源管理器的树状结构，清晰展示远程服务器的文件系统。您可以像操作本地文件一样，浏览、创建、删除、重命名文件和文件夹。

### 拖拽上传与下载

最便捷的功能之一是其对文件拖拽操作的支持。您可以直接将本地文件或文件夹拖拽到远程文件面板中进行上传，或将远程文件拖拽到本地桌面进行下载。这大大提高了文件传输的效率和用户体验。

### 权限与属性修改

FinalShell的SFTP功能还允许您方便地修改远程文件的权限（chmod）和所有者（chown）等属性。右键点击文件或文件夹，选择相应的选项即可进行调整，这对于服务器管理来说是不可或缺的。
