## FinalShell 4.8.0 连不上 SSH？试试这些简单设置！

大家好，我是你们的兼职博主。用 FinalShell 客户端（比如 4.8.0 版本）在 Windows 上连不上 SSH 服务器，是不少朋友常遇到的问题。其实很多时候，问题并不复杂，几个小设置就能搞定。我自己习惯每次遇到连接问题时，都先从最基本的网络检查开始。

### 第一步：排查服务器和网络状况

当 FinalShell 连不上服务器时，先检查后端。

1.  **服务器在线吗？** 尝试 ping 一下你的服务器 IP 地址。如果 ping 不通，那可能是服务器宕机或网络路径有故障。
2.  **SSH 服务运行了吗？** 确保服务器上的 SSH 服务 (`sshd`) 正在运行。
3.  **防火墙挡道没？** 检查服务器防火墙（如安全组规则），确保 22 端口（或你的自定义端口）是开放的，且允许你的 IP 访问。

### 第二步：核对 FinalShell 客户端配置

连接失败很多时候是客户端配置有误。

1.  **IP 和端口：** 仔细核对服务器的 IP 地址和 SSH 端口号（默认为 22）是否正确输入。
2.  **认证信息：** 检查 SSH 用户名和密码。如果用 SSH 密钥，确认加载了正确的私钥，且密码（如果有）也正确。如果你需要更详细的密钥配置教程，可以参考 [FinalShell SSH 密钥配置](/blog/finalshell-ssh-key-configuration/)。
3.  **连接超时：** 针对网络不稳定情况，可以在 FinalShell 会话属性的“高级”选项卡，适当增加“连接超时”时间（比如从 10 秒增加到 30 秒）。

![FinalShell 连接设置界面](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

### 第三步：尝试交叉验证

如果前两步还没解决，试试排除法。

1.  **换个网络：** 比如从 Wi-Fi 切换到手机热点，看看是不是本地网络问题。
2.  **用其他客户端：** 试试 PuTTY 或 Windows 自带的 `ssh` 命令。如果其他工具也连不上，问题多半在服务器端。如果是 FinalShell 特有的问题，考虑重装客户端。关于 FinalShell 在 Windows 上的安装，可以看这篇：[FinalShell Windows 安装指南](/blog/finalshell-windows-install-guide/)。FinalShell 除了连接，文件传输也很方便，比如 [FinalShell SFTP 文件传输](/blog/finalshell-sftp-file-transfer/)。

## 常见问题

### 问：连接时提示 `Permission denied` 怎么办？

**答：** 这通常是认证信息不对。检查用户名、密码或 SSH 私钥是否正确。服务器上 `~/.ssh/authorized_keys` 文件权限也需检查，通常设为 600。

### 问：连接后操作卡顿或响应慢怎么办？

**答：** 可能是网络延迟高或服务器负载重。尝试增加 FinalShell 的“连接超时”时间。如果服务器在国外，考虑网络连接。有端口转发需求的朋友，可以参考 [FinalShell 端口转发指南](/blog/finalshell-port-forwarding-guide/)。
