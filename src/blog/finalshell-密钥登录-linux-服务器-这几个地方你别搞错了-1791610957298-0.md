## FinalShell 密钥登录 Linux 服务器实操

SSH 密钥登录的核心是生成一对密钥（公钥和私钥），然后把公钥放到服务器上，私钥留在本地。FinalShell 会用私钥来证明你的身份。

### 1. 生成 SSH 密钥对

首先，我们需要在本地生成一对 SSH 密钥。FinalShell 内置了密钥生成器，非常方便。如果你已经有现成的密钥对，也可以跳过这一步。

1.  打开 FinalShell，点击顶部菜单栏的“**工具**” -> “**SSH 密钥生成器**”。
2.  在弹出的窗口中，选择密钥类型（通常使用 RSA 或 ED25519），设置密钥长度（推荐 2048 位或更高）。你可以为私钥设置一个密码（Passphrase），这样即使私钥被盗，没有密码也无法使用，安全性更高。如果你觉得麻烦，也可以留空，但请务必妥善保管好你的私钥文件。
3.  点击“**生成**”按钮。生成完成后，会显示公钥内容。同时，确保点击“**保存私钥**”和“**保存公钥**”，把它们保存到你本地电脑的安全位置，例如 `C:\Users\你的用户名\.ssh\` 目录。**记住私钥文件是你的身份凭证，绝不能泄露！**

### 2. 服务器端配置公钥

有了公钥，下一步就是把它放到你的 Linux 服务器上。这一步需要你先用密码或者其他方式连接上服务器。

1.  用 FinalShell （或其他方式，如密码）登录到你的 Linux 服务器。如果你是第一次连接，可以参考这篇 [FinalShell Windows 安装使用指南](/blog/finalshell-windows-install-guide/)。
2.  在服务器上，进入当前用户的家目录，并创建一个名为 `.ssh` 的隐藏目录（如果它不存在的话）：
    ```bash
    mkdir -p ~/.ssh
    ```
    然后，修改该目录的权限，确保只有所有者才能读写执行：
    ```bash
    chmod 700 ~/.ssh
    ```
3.  接下来，把你在第一步中生成的公钥内容（通常以 `.pub` 结尾的文件里的内容）添加到 `~/.ssh/authorized_keys` 文件中。你可以使用 `cat` 命令、`echo` 命令或者 `vi`/`nano` 等编辑器。**注意：如果你已经有 `authorized_keys` 文件，请把新的公钥追加进去，而不是覆盖它。一行一个公钥。**
    假设你的公钥内容是 `ssh-rsa AAAAB3NzaC... your_email@example.com`，你可以这样做：
    ```bash
    echo "ssh-rsa AAAAB3NzaC... your_email@example.com" >> ~/.ssh/authorized_keys
    ```
    替换 `ssh-rsa AAAAB3NzaC... your_email@example.com` 为你自己的公钥内容。我自己习惯用 `vi` 编辑器，这样可以更直观地检查文件内容。
4.  最后，修改 `authorized_keys` 文件的权限，只允许所有者读写：
    ```bash
    chmod 600 ~/.ssh/authorized_keys
    ```

### 3. FinalShell 配置密钥连接

现在，公钥已经在服务器上配置好了，我们可以回到 FinalShell 来设置用私钥连接了。

1.  在 FinalShell 主界面点击左上角的“**连接**”图标（或“文件”->“新建连接”），选择“**SSH 连接**”。
2.  填写连接信息：
    *   **名称**：给你的连接起个名字，方便识别。
    *   **主机**：你的服务器 IP 地址或域名。
    *   **端口**：SSH 端口，默认为 22，如果你的服务器修改了，请填写对应的端口。
    *   **认证方式**：选择“**公钥**”。
    *   **用户**：你的 Linux 用户名，比如 `root` 或 `ubuntu`。
    *   **私钥文件**：点击右侧的文件夹图标，找到你之前保存在本地的私钥文件（通常没有文件后缀，或者 `.pem`、`.key` 等）。
    *   **私钥密码**：如果你在生成私钥时设置了密码，这里需要输入。
3.  点击“**确定**”保存连接配置，然后尝试连接。如果一切顺利，你应该就能通过密钥成功登录到你的服务器了！关于更详细的 SSH 密钥配置，可以参考这篇 [FinalShell SSH 密钥配置详细教程](/blog/finalshell-ssh-key-configuration/)。

## 常见问题

密钥登录虽然方便，但配置过程中也容易遇到一些问题。这里列举几个常见的，帮你快速排查。

*   **私钥文件格式不对？** FinalShell 支持 OpenSSH 格式的私钥。如果你是从其他工具（如 PuTTY）生成的 `.ppk` 文件，可能需要先转换一下。FinalShell 自身的密钥生成器生成的格式通常可以直接用。
*   **连接失败，提示权限问题？** 这通常是服务器上的 `~/.ssh` 目录或 `authorized_keys` 文件的权限设置不正确。请务必检查并设置为 `chmod 700 ~/.ssh` 和 `chmod 600 ~/.ssh/authorized_keys`。
*   **公钥没添加到 `authorized_keys` 文件中？** 仔细检查 `authorized_keys` 文件内容，确保你的公钥完整地粘贴进去了，并且在一行。有时复制粘贴时会引入多余的换行符或空格。
*   **服务器防火墙端口没开？** 确保你的服务器防火墙（如 `ufw` 或 `firewalld`）允许 22 端口（或你自定义的 SSH 端口）的入站连接。你也可以尝试临时关闭防火墙进行测试。
*   **忘记私钥密码？** 如果你在生成私钥时设置了密码，但忘记了，那么这个私钥就无法使用了。你需要重新生成密钥对并重复上述步骤。
*   **想通过 FinalShell 传输文件怎么办？** FinalShell 集成了 SFTP 功能，在连接成功后，左侧的文件管理区域就可以直接拖拽文件进行传输。这比传统的 SCP 命令方便得多。想了解更多关于文件传输的内容，可以看看这篇 [FinalShell SFTP 文件传输指南](/blog/finalshell-sftp-file-transfer/)。
