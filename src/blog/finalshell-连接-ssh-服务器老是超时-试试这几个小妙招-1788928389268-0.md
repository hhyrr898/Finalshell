## FinalShell 连接 SSH 服务器老是超时？试试这几个小妙招

各位小伙伴，FinalShell 连接服务器却遇到“连接超时”？别急！今天我就以 **FinalShell 4.8.18 版本**在 Windows 上的经验，分享几个常用妙招，帮你快速解决！

遇到连接超时，通常是网络、配置或服务器端问题。我自己习惯从简到繁排查。

### 第一步：检查网络与防火墙

这是基础且关键。

1.  **本地网络：** 确保电脑能上网。Ping 服务器 IP，不通先解决网络。
2.  **服务器防火墙：** 服务器（如 `firewalld` 或 `ufw`）可能未开放 SSH 端口（默认 22）。确保安全组或防火墙允许 22 端口访问。不熟悉安全组？参考 [/blog/finalshell-port-forwarding-guide/](/blog/finalshell-port-forwarding-guide/)。

### 第二步：核对连接信息和凭证

配置易出错。

1.  **IP 和端口：** 仔细检查 FinalShell 里填写的服务器 IP 和 SSH 端口，确保无误。非默认端口尤其容易输错。
2.  **用户名/密码/密钥：** 确认凭证正确。如用 SSH 密钥，检查路径和密码。更多配置参考 [/blog/finalshell-ssh-key-configuration/](/blog/finalshell-ssh-key-configuration/)。

![排查SSH连接问题](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

### 第三步：调整 FinalShell 连接超时设置

特定网络下，默认超时可能不够。

1.  **进入设置：** 选中服务器连接，右键“修改”。
2.  **增加超时：** 在配置中找到“连接超时”，从默认 15 秒调长至 30 或 60 秒。这能给 FinalShell 更多时间建立连接。

这三步通常能解决大部分 SSH 连接超时问题。仍有问题，请查看服务器 SSH 服务日志（如 `/var/log/auth.log`）获取详细错误。

## 常见问题

### Q1：我能 ping 通服务器，但 FinalShell 还是连不上？

**A1：** Ping 仅表明网络可达（ICMP），SSH 连接（TCP）需特定端口。连不上多是 SSH 端口未开放（防火墙）、SSH 服务未启动/配置错，或连接凭证不正确导致。请核对防火墙和 SSH 服务状态。

### Q2：FinalShell 文件传输慢，有什么办法吗？

**A2：** SFTP 速度受网络、服务器性能及本地磁盘影响。尝试更换网络，检查服务器负载。小文件受延迟影响大，大文件可考虑压缩。更多技巧，参考 [/blog/finalshell-sftp-file-transfer/](/blog/finalshell-sftp-file-transfer/)。
