想访问公司内网服务，或让外网连接本地开发环境？FinalShell 的端口转发功能是你的救星，它能安全高效地解决这些网络连接难题。今天，我将以 FinalShell 4.5.12 为例，手把手教你如何配置本地和远程转发。

## 本地转发：访问远程内网服务
本地转发（Local Forwarding）能将你本地端口映射到远程服务器可访问的目标地址和端口，让你直接访问远程内网服务。

### 步骤一：创建或编辑会话
打开 FinalShell，新建或编辑一个 SSH 会话，确保它能连接到你的跳板机。

### 步骤二：添加本地转发规则
连接成功后，进入会话的“隧道”选项卡。点击“新建”，选择“本地转发”。

填入：

*   **本地监听端口:** 你本地要用的端口，如 `8080`。
*   **远程目标地址:** 目标服务的 IP 或域名，如 `192.168.1.100`。
*   **远程目标端口:** 目标服务端口，如 `3306` (MySQL)。

我一般会先测试目标服务是否可达。保存规则并启用。

### 步骤三：通过本地端口访问
保持 FinalShell 会话连接，现在你就可以通过 `http://localhost:8080` 或 `localhost:8080` 连接到 `192.168.1.100:3306` 上的服务了。

为了防止会话配置丢失，建议你定期[备份 FinalShell 会话配置](/blog/finalshell-backup-session-config/)。

## 远程转发：让本地服务被外网访问
远程转发（Remote Forwarding）允许远程服务器端口映射到你本地服务端口，用于将本地开发服务暴露给远程或外网访问。

### 步骤一：创建或编辑会话
打开 FinalShell 并连接远程跳板机。确保你的本地服务已运行并监听特定端口。

### 步骤二：添加远程转发规则
进入会话“隧道”选项卡，点击“新建”，选择“远程转发”。

填入：

*   **远程监听端口:** 远程服务器监听端口，如 `9000`。
*   **本地目标地址:** 本地机器 IP，通常是 `127.0.0.1`。
*   **本地目标端口:** 本地服务监听端口，如 `80` 或 `5000`。

保存并启用规则。

### 步骤三：通过远程端口访问本地服务
保持 FinalShell 会话连接，现在远程服务器上的机器通过 `IP:9000` 即可访问你本地 `localhost:80` 的服务了。方便演示或调试。

如果在使用中遇到乱码问题，可以参考这篇[FinalShell 编码字符集问题修复](/blog/finalshell-encoding-charset-fix/)。

## 常见问题

*   **转发不成功怎么办？** 确认端口未被占用，目标 IP 和端口无误，并检查防火墙设置。远程转发时，服务器可能需要配置 `GatewayPorts yes`。
*   **连接断开后转发失效？** 端口转发依赖于 SSH 会话。会话断开即失效，可设置自动重连。
