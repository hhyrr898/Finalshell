## FinalShell 4.5.12，Windows 客户端新会话配置心得！

FinalShell 作为我日常开发调试的主力工具，其强大的功能和直观的界面一直深得我心。上周我将 FinalShell 升级到了 4.5.12 版本，发现有些老习惯需要稍微调整一下才能更顺手。尤其是对于刚接触的新手，或者需要频繁创建新会话的朋友，可能会觉得初次配置有点摸不着头脑。今天，我就来分享一下我在 Windows 客户端上配置新会话的一些小技巧和心得，希望能帮助大家少走弯路。

![配图说明](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

### 快速创建 SSH 会话

创建 SSH 会话是 FinalShell 最基础也是最重要的功能之一。这里我们以连接一台远程 Linux 服务器为例，看看具体怎么操作。

### 步骤一：填入基础连接信息

打开 FinalShell 客户端后，点击左上角的“连接”按钮，然后选择“SSH”新建一个会话。弹出的窗口中，你需要填写以下关键信息：

*   **名称：** 给你的会话起个名字，方便识别，比如“我的开发服务器”。
*   **主机：** 远程服务器的 IP 地址或域名。
*   **端口：** SSH 服务端口，默认为 22。如果你修改过，记得填写正确端口。
*   **用户：** 登录服务器的用户名，通常是 `root` 或者你创建的普通用户。
*   **密码：** 登录用户的密码。

### 步骤二：选择合适的认证方式

除了密码认证，FinalShell 也支持密钥认证，这在安全性上更胜一筹。如果你已经配置了 SSH 密钥，可以在这里选择“公钥认证”，然后上传你的私钥文件。关于如何生成和配置 SSH 密钥，可以参考我们之前的文章：[FinalShell 的 SSH 密钥配置](/blog/finalshell-ssh-key-configuration/)。

如果你是第一次使用 FinalShell，或者对 Windows 上的安装过程有疑问，可以查阅 [FinalShell Windows 安装指南](/blog/finalshell-windows-install-guide/)。

### 步骤三：保存与首次连接测试

填写完所有信息后，点击右下角的“连接”按钮。FinalShell 会尝试连接你的服务器。如果是首次连接，可能会弹出确认指纹的提示，选择“是”即可。如果一切顺利，你就会看到服务器的命令行界面了。

连接成功后，记得点击“保存”按钮，将你的会话配置保存下来，下次就能直接从左侧列表点击连接了。

### 你的会话体验

成功连接只是第一步，为了更好的使用体验，我还会做一些小调整。比如，在“会话设置”里，我通常会把“终端编码”设置为 `UTF-8`，这样可以有效避免中文乱码问题。同时，如果你需要进行文件传输，FinalShell 也内置了 SFTP 功能，你可以通过它轻松管理服务器文件，具体操作可以看这篇文章：[FinalShell 的 SFTP 文件传输技巧](/blog/finalshell-sftp-file-transfer/)。

### 常见问题

*   **连接失败，提示“Connection refused”或“Connection timed out”？**
    这通常是服务器防火墙没有开放 SSH 端口（默认为 22），或者 SSH 服务没有运行。检查服务器安全组规则，并确保 `sshd` 服务正在运行。
*   **终端显示乱码？**
    多半是编码设置问题。请进入会话设置，将“终端编码”改为 `UTF-8`，然后重新连接。如果服务器端也是 UTF-8 编码，这样基本就能解决。
