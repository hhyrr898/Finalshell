## FinalShell 4.8.9 连不上服务器？三招快速搞定！

遇到 FinalShell 4.8.9 SSH 连接问题？别慌！作为一名兼职作者，我整理了一套实用的排查步骤，帮你快速定位并解决服务器连接故障。

### 第一步：检查你的本地环境

问题可能出在你自己的电脑上。

1.  **网络连通性：** 打开命令行，`ping 你的服务器IP`。如果 ping 不通，先检查本地网络。能 ping 通则网络路径没问题。
2.  **本地防火墙：** Windows 防火墙可能阻止 FinalShell。尝试暂时关闭防火墙。如果连接成功，记得给 FinalShell 添加例外。更多 Win 安装细节：[/blog/finalshell-windows-install-guide/](/blog/finalshell-windows-install-guide/)

### 第二步：确认服务器端状态

本地没问题，就看服务器了。

1.  **SSH 服务：** 通过 VNC 或云控制台登录，检查 SSH 服务（`sshd`）是否运行。Linux 上用 `systemctl status sshd`。
2.  **端口与安全组：** 确保服务器防火墙（如 `ufw`）的 SSH 端口（默认为 22）已开放。云服务器还需检查安全组入站规则。端口转发参考：[/blog/finalshell-port-forwarding-guide/](/blog/finalshell-port-forwarding-guide/)

### 第三步：核对 FinalShell 配置

最后回到 FinalShell 客户端，仔细核对连接设置。

1.  **地址与端口：** 确认服务器 IP 地址和 SSH 端口号准确无误。
2.  **认证信息：** 检查登录用户名、密码。使用密钥登录时，确保密钥路径、权限正确且匹配。密钥配置：[/blog/finalshell-ssh-key-configuration/](/blog/finalshell-ssh-key-configuration/)

### 常见问题

*   **问：提示 "Connection refused"？**
    *   答：服务器拒绝连接。原因多是 SSH 服务未启动、端口不通或防火墙拦截。检查服务器端。

*   **问：服务器 IP 动态变化怎么办？**
    *   答：动态 IP 需手动更新 FinalShell。建议使用域名，或为云服务器配置固定公网 IP。
