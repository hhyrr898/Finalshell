## FinalShell 常见使用问题解答

### FinalShell 连不上服务器，一直显示连接超时或认证失败怎么办？

这是 FinalShell 用户最常见的问题。我记得自己刚开始用 FinalShell 4.9.0 版本时，有次连新服务器，死活显示认证失败，排查了半天。

首先，检查**网络连接**：确保你的电脑能访问互联网，服务器 IP 正确，且服务器 SSH 服务在运行。可用 `ping` 命令测试。

接着，**SSH 认证信息**是关键：
1.  **用户名和密码：** 务必确认输入无误。
2.  **密钥认证：** 若用 SSH 密钥，检查私钥文件是否正确加载到 FinalShell，且私钥密码（如果有）输入正确。支持 `.pem` 或 `.ppk`。可参考 [FinalShell SSH 密钥配置教程](/blog/finalshell-ssh-key-configuration/)。
3.  **端口号：** 默认 SSH 端口是 22。若服务器修改端口，核对 FinalShell 会话配置与服务器实际端口是否一致。

最后，**防火墙**是常见障碍：
-   **服务器防火墙：** 检查服务器防火墙（如 `firewalld` 或 `ufw`）是否允许 SSH 端口入站连接。例如，Ubuntu 可用 `sudo ufw allow 22`。
-   **云服务商安全组：** 若是云主机，检查**安全组**设置，确保允许你的 IP 地址或所有 IP 通过 SSH 端口访问。

### FinalShell 怎么快速上传下载文件，SFTP 传输速度慢怎么办？

FinalShell 内置 SFTP 功能方便快捷。

要上传下载文件：
1.  **连接服务器：** 正常连接到服务器会话。
2.  **打开 SFTP 窗口：** 连接成功后，点击界面上方“SFTP”图标，弹出左右分栏的文件管理器。
3.  **拖拽传输：** 直接从本地拖拽到服务器，或从服务器拖拽到本地。也可右键选择“上传”或“下载”。

关于 SFTP 传输速度慢的问题：
这常与**网络环境**、**服务器带宽**及**文件大小**有关。
-   **网络环境/服务器带宽：** 检查本地和服务器的带宽情况。
-   **传输模式：** 小文件打包传输更快。超大文件可考虑使用 `scp` 命令。可参考 [FinalShell SFTP 文件传输的详细指南](/blog/finalshell-sftp-file-transfer/)。

### 在 FinalShell 里如何连接 Docker 容器内部？

进入 Docker 容器内部调试或查看日志很常见。FinalShell 可轻松实现。

1.  **连接宿主机：** 首先通过 FinalShell 连接到运行 Docker 的服务器。
2.  **查看容器 ID 或名称：** 在宿主机命令行输入 `docker ps`，找到目标容器。
    ```bash
    docker ps
    ```
3.  **进入容器：** 使用 `docker exec -it [容器ID或名称] /bin/bash` (或 `/bin/sh`)。
    ```bash
    docker exec -it my_container_name /bin/bash
    ```
    执行后，FinalShell 终端会话即切换到容器命令行。输入 `exit` 退出。

### FinalShell 会话总是无故闪退或者卡住不动怎么办？

FinalShell 会话闪退或卡顿很恼人，原因可能包括：

1.  **资源占用过高：** FinalShell 自身需内存。多应用或大量会话可能导致响应慢或崩溃。
2.  **网络波动：** SSH 连接对网络稳定性有要求。本地或服务器网络不稳定都可能中断会话。
3.  **服务器端问题：** 服务器负载高或 SSH 服务不稳定也可能导致客户端卡顿。
4.  **FinalShell 软件版本：** 确保使用如 FinalShell 4.9.0 般较新版本。旧版可能有 bug。可尝试从官网更新，更新前备份会话配置。

### 怎么在 FinalShell 里设置端口转发？

端口转发能让你通过本地端口访问远程服务器服务。FinalShell 支持本地和远程转发。

以**本地端口转发**为例：通过本地 `8080` 端口访问服务器上 `80` 端口的 Web 服务。

1.  **编辑会话：** 右键点击目标服务器连接，选择“属性”或“编辑会话”。
2.  **进入隧道配置：** 在会话配置窗口中，找到“隧道”或“转发”选项卡。
3.  **添加本地转发：**
    -   点击“添加”。
    -   选择“本地转发”。
    -   “本地端口”填 `8080`。
    -   “远程主机”填 `127.0.0.1`。
    -   “远程端口”填 `80`。
    -   勾选“启用”，点击“确定”保存。

保存并重新连接后，访问本地 `http://localhost:8080` 即访问服务器上的 `http://127.0.0.1:80` 服务。此功能在开发调试时极有用。更多详情，请查看 [FinalShell 端口转发指南](/blog/finalshell-port-forwarding-guide/)。

## 常见问题

### FinalShell 的会话配置太多，怎么管理和备份？

FinalShell 会话配置保存在本地。利用分组功能可有效管理：右键点击会话列表空白处，“新建分组”，将相关会话拖入。

备份时，找到 FinalShell 安装目录（Windows 通常在 `C:\Users\你的用户名\AppData\Roaming\FinalShell`），将 `sessions` 文件夹定期复制即可。

### 为什么我设置的 FinalShell 主题或字体，重启后又恢复默认了？

这可能是 FinalShell 没有权限写入配置文件，或绿色版运行时未正确保存。确保 FinalShell 运行目录有足够权限。对于绿色版，尝试在其运行目录创建 `.config` 文件夹。若仍无效，尝试以管理员身份运行 FinalShell，修改设置保存后再正常启动。
