## FinalShell 4.5.12 连不上服务器？别急，我帮你捋清常见问题！

嗨！FinalShell 4.5.12 版本在 Windows 上连接服务器遇到问题，这很常见。我自己也经常碰到，但排查起来其实有章可循。今天就来分享下我的快速排查思路。

### 第一步：基础网络通不通？先 Ping！

这是最基础的。在怀疑 FinalShell 软件前，先确认服务器可达。
1.  **打开 CMD：** Windows 搜索栏输入 `cmd` 回车。
2.  **Ping 服务器 IP：** 输入 `ping 你的服务器IP地址`。
3.  **看结果：** 如果显示 `Request timed out` 或 `Destination Host Unreachable`，那就是网络不通，得先解决网络问题。Ping 通了再看下一步。

### 第二步：SSH 端口和服务器防火墙对不对？

网络通了，问题可能在端口或防火墙。
1.  **检查 FinalShell 端口：** 在 FinalShell 连接配置里，确认 SSH 端口号。默认 22，可能被更改。不确定如何配置？参考这篇：[/blog/finalshell-windows-install-guide/](/blog/finalshell-windows-install-guide/)。
2.  **检查服务器防火墙：** 服务器本身的防火墙（如 `ufw`）必须放行 SSH 端口。你需要通过 VNC 或网页管理界面登录服务器，检查并开放。
3.  **检查安全组：** 云服务器还要检查安全组规则，确保 SSH 端口对你的 IP 开放。

![通过FinalShell连接服务器的示意图](/static/images/photo-1486406146926-c627a92ad1ab.jpg)

### 第三步：认证信息和客户端设置有问题？

排除网络和端口，那多半是登录信息或客户端设置。
1.  **用户名和密码/密钥：** 仔细核对 FinalShell 中的用户名、密码或 SSH 密钥。大小写、文件路径都要正确。密钥配置看这里：[/blog/finalshell-ssh-key-configuration/](/blog/finalshell-ssh-key-configuration/)。
2.  **代理设置：** 如果你用了代理，尝试在 FinalShell 连接属性中禁用代理，直连试试。我自己习惯这样快速排除代理问题。
3.  **客户端日志：** FinalShell 连接失败时会给出错误信息。仔细阅读这些日志，它们通常会直接指出问题所在，比如“认证失败”。

### 常见问题

#### Q1: FinalShell 提示“连接被拒绝”怎么办？
A: 通常指 SSH 服务未运行、端口不正确或服务器防火墙拦截。请重点复查第二步。

#### Q2: 如何查看 FinalShell 的详细错误日志？
A: FinalShell 连接窗口下方或右侧有详细日志。寻找“Error”或“Failed”字样，它们是定位问题的关键线索。
